# Emantoresu Portfolio Site

This repository contains a personal portfolio site designed for Emantoresu.

## Deployment

This site is designed to be deployed as a GitHub Page.

### Content

- `index.html`: The home page of the portfolio site.
- `about.html`: Information about the author.
- `blog.html`: A blog section.
- `projects.html`: Showcases of work and projects.
- `speaking.html`: Information about speaking engagements.
- `toolbox.html`: A collection of favorite tools and resources.
- `style.css`: The styling for the entire site.
